Dies ist ein einfaches Template für Hausarbeiten an der DHBW.

# Installation
"Use this template" anklicken um ein neues Repository mit diesem Template zu erzeugen.

# Komponenten
In `config.typ` kann man Parameter, wie Sprache, Name, Matrikelnummer, etc. einstellen

In `content/content.typ` kommt der Inhalt rein.

In `content/abstract.typ` schreibt man seinen Abstract.

In `util.typ` findet man Hilfsfunktionen.

# Q&A
**Q**: Warum kompiliert die Vorlage nicht, obwohl ich nichts geändert habe?

**A**: Im Template werden Funktionen benutzt, die in älteren Typst Versionen (vor 0.14.2) möglicherweise nicht existieren. In den aller meisten Fällen sollte es also ausreichen Typst zu updaten.

**Q**: Kann ich dieses Template für die TXXXX-Arbeiten benutzen?

**A**: Nein, dieses Template erfüllt nicht die Vorgaben für eine TXXXX-Arbeit. Dafür muss man entweder dieses Template selbst anpassen oder ein existierendes Template runterladen. Templates kann man, unter anderem, im [Typst Universe](https://typst.app/universe/) finden.
